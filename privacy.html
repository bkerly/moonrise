Moonrise Privacy Policy

Last updated: October 30, 2026

Moonrise is a private family calendar run by Brian Erly for his own household. It is not offered to the public.

What it accesses

  • Google Calendar: events on calendars shared with moonrise.erly@gmail.com, so it can show them and add or change events.
  • Gmail (read only): messages sent to moonrise.erly@gmail.com, so it can find dates in forwarded emails and turn them into calendar events. It does not access any other inbox.

How the data is used and stored

  • Email text is processed on a computer in the household. It is not sent to any outside service.
  • Calendar data stays in Google Calendar and on that same computer.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services

Moonrise's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
